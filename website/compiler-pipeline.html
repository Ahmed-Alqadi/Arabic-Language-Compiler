                    المرحلة الأولى
                    
1. التحليل المعجمي (Lexer)

                    
الهدف: تحويل تسلسل المحارف النصية العربية إلى وحدات معجمية ذات معنى تسمى Tokens.

                    
    
                        
  • • تطبيع الحروف: توحيد الهمزات (أ، إ، آ -> ا) والياء والألف المقصورة لتجنب الأخطاء الإملائية.
    • 
                        
  • • تجاهل المسافات والتعليقات: دعم التعليقات أحادية السطر // والكتلية /* ... */.
    • 
                        
  • • المخرجات: ملف tokens.json وجدول تفاعلي في الواجهة.
    • 
                    

                


                
                

                    المرحلة الثانية
                    
2. التحليل النحوي (Parser)

                    
الهدف: التحقق من مطابقة تسلسل الرموز لقواعد النحو الرسمية EBNF وبناء شجرة الإعراب المجردة AST.

                    
    
                        
  • • نوع المحلل: محلل انحداري تعاودي LL(1) بدون تكرار يساري (Left Recursion).
    • 
                        
  • • معالجة الأسبقية: تطبيق أسبقية العمليات (الأقواس، الأسس ^، الضرب والقسمة، الجمع والطرح).
    • 
                        
  • • المخرجات: شجرة نصية parse-tree.txt وهرمية parse-tree.json.
    • 
                    

                


                
                

                    المرحلة الثالثة
                    
3. التحليل الدلالي (Semantic)

                    
الهدف: فحص صحة المعاني، التحقق من مطابقة الأنواع، وبناء جداول الرموز متداخلة النطاقات.

                    
    
                        
  • • التحقق من الإعلانات: منع استخدام أي متغير قبل تعريفه، ومنع تكرار تعريف المعرف في نفس النطاق.
    • 
                        
  • • حماية الثوابت: إصدار خطأ دلالي فوري عند محاولة إعادة إسناد قيمة لثابت.
    • 
                        
  • • المخرجات: symbols.json و semantic-errors.json.
    • 
                    

                


                
                

                    المرحلة الرابعة
                    
4. توليد الكود الوسيط (3AC)

                    
الهدف: تفكيك الجمل المعقدة إلى تعليمات وسيطة خطية ثلاثية العناوين (Three-Address Code).

                    
    
                        
  • • المتغيرات المؤقتة: إنشاء متغيرات مؤقتة للمتتاليات الحسابية (ت1، ت2...).
    • 
                        
  • • عناوين القفز: توليد علامات القفز الشرطي وغير الشرطي لإدارة حلقات طالما و كرر و اذا.
    • 
                        
  • • المخرجات: three-address-code.txt.
    • 
                    

                


                
                

                    المرحلة الخامسة
                    
5. توليد لغة التجميع (Assembly)

                    
الهدف: ترجمة الكود الوسيط إلى شفرة لغة تجميع تحاكي المعالج الفعلي (x64 / ArabicVM).

                    
    
                        
  • • قسم البيانات (.data): تخصيص الذاكرة للمتغيرات والثوابت والنصوص بسلاسل Null-terminated.
    • 
                        
  • • قسم التعليمات (.text): توليد أوامر النقل والعمليات الحسابية والنداء (MOV, ADD, SUB, CALL, SYSCALL).
    • 
                        
  • • المخرجات: ملف assembly-code.asm.
    • 
                    

                


                
                

                    المرحلة السادسة
                    
6. الآلة الافتراضية والتنفيذ (VM)

                    
الهدف: بيئة تشغيل متكاملة في الذاكرة لتنفيذ الكود وإدارة مكدس المعاملات والإدخال/الإخراج.

                    
    
                        
  • • إدارة الإجراءات: دعم تمرير المتغيرات بالقيمة وبالمرجع بالمرجع بتعديل مباشر للمتغير الأصلي.
    • 
                        
  • • التفاعل مع المستخدم: استقبال المدخلات عبر اقرأ وطباعة النتائج عبر اطبع.
    • 
                        
  • • المخرجات: شاشة المخرجات وملف output.txt.
    •
