ArabicCompiler.Core

مكتبة فئات مستقلة تضم نواة المترجم بمراحله الست: المعجم، النحو، جدول الرموز، الفحص الدلالي، الكود ثلاثي العناوين (3AC)، توليد Assembly، والآلة الافتراضية (VM).

ArabicCompiler.Cli

المترجم التنفيذي المستقل لسطر الأوامر (Command-Line Interface). يمكن تشغيله مباشرة من PowerShell لترجمة أي ملف .arb وتصدير كافة مخرجات المراحل.

ArabicLanguageEditor

بيئة تطوير متكاملة (WPF IDE) تدعم الكتابة باللغة العربية من اليمين إلى اليسار (RTL)، مع 8 ألسنة تبويب لعرض كافة نتائج الترجمة وجدول الرموز والأخطاء.

بنية اللغة العربية

كود عربي فصيح ذو قواعد نحوية صارمة

تدعم اللغة البرمجية الكلمات المحجوزة العربية، تطبيع الهمزات، حماية الثوابت، الأنواع الأولية والمركبة، الحلقات الثلاث، والتمرير بالمرجع:

  • ✓ الأنواع الأولية: صحيح، حقيقي، منطقي، حرفي، نصي
  • ✓ الأنواع المركبة: سجل { ... } والمصفوفات مصفوفة [1..10] من صحيح
  • ✓ حلقات التكرار: طالما، كرر..حتى، كرر..الى..خطوة
  • ✓ الإجراءات مع التمرير بالقيمة وبالمرجع بالمرجع
