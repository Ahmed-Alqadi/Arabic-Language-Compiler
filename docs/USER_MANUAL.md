# دليل المستخدم والتشغيل السريع (User & Operation Manual)
## محرر لغة البرمجة العربية ومترجم سطر الأوامر المستقل

---

## 1. متطلبات التشغيل (System Requirements)
- **نظام التشغيل**: Windows 10 أو Windows 11 (64-bit).
- **بيئة التشغيل**: .NET Runtime 10.0 أو .NET Desktop Runtime (تم بناء البرامج المنشورة بنمط متوافق).
- **الخطوط الموصى بها**: خط يدعم العربية بوضوح مثل Segoe UI، Consolas، أو Courier New.

---

## 2. كيفية تشغيل المحرر الرسومي (ArabicLanguageEditor.exe)

1. توجه إلى المجلد:
   ```
   ArabicCompilerSolution/publish/editor/
   ```
2. انقر نقراً مزدوجاً على الملف التنفيذي:
   ```
   ArabicLanguageEditor.exe
   ```
3. ستفتح واجهة المحرر الحديثة المجهزة بنظام الألوان الداكن المريح للعين ومحاذاة اليمين إلى اليسار (RTL).

---

## 3. مميزات وتفاصيل واجهة المحرر الرسومي

```
+-------------------------------------------------------------------------------+
|  محرر لغة البرمجة العربية - Arabic Language IDE                                  |
+-------------------------------------------------------------------------------+
| [جديد] [فتح ملف] [حفظ] [حفظ باسم] | [اختر مثالاً v] | [ترجمة فقط] [ترجمة وتشغيل] | [⇄] |
+-------------------------------------------------------------------------------+
|  محرر الأكواد من اليمين إلى اليسار (RTL) |  لوحة النتائج والمخرجات (8 ألسنة تبويب)  |
|  1 | برنامج اختباري؛                   |  1. الرموز المعجمية (Tokens)         |
|  2 | {                               |  2. شجرة الإعراب النحوي (Parse Tree) |
|  3 |     متغير س: صحيح؛              |  3. جدول الرموز (Symbols)             |
|  4 |     س = 15؛                     |  4. الفحص الدلالي (Semantic)          |
|  5 |     اطبع(س)؛                    |  5. الكود الوسيط (3AC)                |
|  6 | }.                              |  6. لغة التجميع (Assembly)            |
|                                      |  7. الأخطاء (Errors)                 |
|                                      |  8. شاشة الإخراج (Console Output)    |
+-------------------------------------------------------------------------------+
|  مدخلات البرنامج: [________________________] [إرسال المدخلات والتنفيذ]        |
|  الحالة: تمت الترجمة بنجاح | الأخطاء: 0 | السطر: 1 | العمود: 1 | [فتح مجلد المخرجات] |
+-------------------------------------------------------------------------------+
```

### أزرار شريط الأدوات:
- **`جديد` (New File)**: يفرغ المحرر ويبدأ قالباً برمجياً جديداً.
- **`فتح ملف` (Open)**: يفتح مربع حوار لاختيار أي ملف برمجي بامتداد `.arb`.
- **`حفظ` (Save)** و **`حفظ باسم` (Save As)**: لحفظ الأكواد المكتوبة بصيغة UTF-8.
- **قائمة الأمثلة الجاهزة (Examples Dropdown)**: تتيح لك بنقرة واحدة تحميل أي من الأمثلة الاثني عشر المعيارية المرفقة مع المشروع.
- **`ترجمة فقط` (Compile)**: يقوم بتشغيل مراحل التحليل المعجمي، النحوي، الدلالي، وتوليد الكود الوسيط وكود التجميع دون تشغيل البرنامج.
- **`ترجمة وتشغيل` (Run)**: يقوم بتشغيل كافة مراحل المترجم، ثم يقوم بتشغيل البرنامج فوراً عبر الآلة الافتراضية (Virtual Machine) وعرض المخرجات في تبويب `شاشة الإخراج`.
- **`⇄ اتجاه النص` (Toggle Direction)**: زر سريع للتبديل بين اتجاه اليمين-إلى-اليسار (RTL) واليسار-إلى-اليمين (LTR).

### لوحة ألسنة التبويب الثمانية (The 8 Tabs):
1. **الرموز المعجمية (Tokens)**: جدول تفصيلي يعرض كل رمز مستخرج، رقمه، نوعه الفني، كلمته الأصلية، ورقم السطر والعمود.
2. **شجرة الإعراب (Parse Tree)**: رسم هرمي منظم لعقد الشجرة النحوية المجردة (AST).
3. **جدول الرموز (Symbols)**: جدول يوضح جميع المتغيرات، الثوابت، السجلات، والمصفوفات، مع مجالات رؤيتها (Scopes) وأنواعها وقيمها.
4. **الفحص الدلالي (Semantic)**: ملخص حالة التدقيق الدلالي، نطاقات المتغيرات، وقواعد التحقق المطبقة.
5. **الكود الوسيط (3AC)**: عرض تعليمات الكود ثلاثي العناوين المعيارية مع المتغيرات المؤقتة (`_ت1`) وعناوين التفرع.
6. **لغة التجميع (Assembly)**: كود التجميع الكامل مع أقسام البيانات والتعليمات والمسجلات.
7. **الأخطاء (Errors)**: جدول يجمع الأخطاء النحوية والدلالية. **عند النقر المزدوج على أي خطأ، ينتقل مؤشر الفأرة تلقائياً إلى السطر المسبب للخطأ في المحرر**.
8. **شاشة الإخراج (Output)**: الشاشة السوداء المخصصة لعرض نصوص الطباعة الناتجة عن تعليمة `اطبع(...)`.

## 4. كيفية تشغيل مترجم سطر الأوامر المستقل (ArabicCompiler.Cli.exe)

يمكنك تشغيل المترجم من أي موجه أوامر (PowerShell أو CMD) بشكل منفصل:

### الصيغة العامة:
```powershell
.\ArabicCompiler.Cli.exe <مسار_الملف.arb> [خيارات]
```

### الخيارات المتاحة:
- `--out <المجلد>`: تحديد المجلد الذي ستُحفظ فيه ملفات المخرجات العشرة (افتراضياً: مجلد يحمل نفس اسم الملف).
- `--run`: تشغيل البرنامج بعد نجاح الترجمة وعرض المخرجات في سطر الأوامر.
- `--input-data "<القيم>"`: تمرير بيانات الإدخال المسبقة لتعليمة `اقرا`.

### أمثلة عملية:
```powershell
# ترجمة ملف بسيط وتوليد الملفات في مجلد out
.\ArabicCompiler.Cli.exe "examples\01_طباعة_بسيطة.arb" --out "out"

# ترجمة وتشغيل برنامج حسابي وعرض الناتج فوراً
.\ArabicCompiler.Cli.exe "examples\02_متغيرات_وحساب.arb" --run

# تمرير مدخلات مسبقة لأمر القراءة
.\ArabicCompiler.Cli.exe "examples\06_حلقة_طالما.arb" --run --input-data "5 10"
```

## 5. دليل البرامج التجريبية الـ 12 المرفقة

| رقم الملف | اسم البرنامج | الهدف التعليمي والميزة المختبرة |
| :---: | :--- | :--- |
| `01` | `01_طباعة_بسيطة.arb` | طباعة النصوص والأرقام والتحقق من بنية البرنامج الأساسية |
| `02` | `02_متغيرات_وحساب.arb` | تعريف المتغيرات والثوابت، وإسناد القيم وإجراء الجمع |
| `03` | `03_عمليات_حسابية_واسس.arb` | اختبار أسبقية العمليات: الأقواس، الأس `^`، الضرب، والقسمة |
| `04` | `04_عمليات_منطقية.arb` | اختبار العوامل المنطقية: `و`، `او`، `ليس`، والمقارنات |
| `05` | `05_جمل_شرطية.arb` | اختبار `اذا ... حينئذ ... والا ... نهاية` المتداخلة |
| `06` | `06_حلقة_طالما.arb` | اختبار حلقة التكرار بالفحص المسبق `طالما ... كرر` |
| `07` | `07_حلقة_اعد_حتى.arb` | اختبار حلقة التكرار بالفحص اللاحق `كرر ... حتى` و `اعد ... حتى` |
| `08` | `08_حلقة_كرر_عددية.arb` | اختبار حلقة العداد مع تحديد الخطوة `كرر س = 1 الى 10 خطوة 2` |
| `09` | `09_اجراء_ومعاملات.arb` | اختبار الإجراءات وتمرير المعاملات بالمرجع `بالمرجع` وتعديلها |
| `10` | `10_انواع_مركبة.arb` | اختبار الأنواع المركبة: السجلات `سجل` والمصفوفات `مصفوفة` |
| `11` | `11_خطا_نحوي.arb` | اختبار رصد الأخطاء النحوية بدقة (`SYN003`: نسيان الفاصلة المنقوطة) |
| `12` | `12_خطا_دلالي.arb` | اختبار رصد الأخطاء الدلالية بدقة (`SEM003`: محاولة تعديل ثابت) |
