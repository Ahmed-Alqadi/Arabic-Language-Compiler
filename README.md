## 🌟 نظرة عامة على المشروع

مشروع **مترجم لغة البرمجة العربية ومحرر الأكواد الذكي** هو بيئة تطوير وبرمجة متكاملة مصممة من الصفر لدعم لغة برمجية عربية إجرائية وبنائية مستوحاة من عائلة لغات (Pascal / Algol / C). يدعم المترجم كافة قواعد اللغة العربية بما يشمل:
- تطبيع الأحرف والهمزات العربية وتجاهل التعليقات.
- دعم أنواع البيانات الأولية (`صحيح`، `حقيقي`، `منطقي`، `حرفي`، `نصي`).
- دعم الأنواع المركبة: السجلات (`سجل { ... }`) والمصفوفات أحادية وثنائية الأبعاد (`مصفوفة [1..10] من صحيح`).
- دعم الإجراءات والدوال مع التمرير بالقيمة وبالمرجع (`بالمرجع`).
- دعم جمل التحكم والشرط (`اذا ... حينئذ ... والا ... نهاية`) وحلقات التكرار الثلاث (`طالما`، `كرر..حتى`، `كرر..الى..خطوة`).
- دعم أسبقية العمليات الحسابية المعقدة بما فيها الأس `^` وباقي القسمة `%` والعمليات المنطقية (`و`، `او`، `ليس`).
- محرر مرئي متكامل يدعم الكتابة من اليمين إلى اليسار (RTL) مع 8 ألسنة تبويب لعرض كافة مراحل الترجمة والمخرجات.

## ⚙️ مراحل المترجم الست (Compiler Pipeline)

يعمل المترجم وفق بنية هندسية احترافية مكونة من 6 مراحل متتابعة:

1. **التحليل المعجمي (Lexer / Lexical Analysis):**  
   قراءة النص العربي، تطبيع المحارف، إزالة الفراغات والتعليقات، واستخراج الرموز المعجمية (`Tokens`) مع تحديد أرقام السطور والأعمدة ونوع كل رمز.

2. **التحليل النحوي (Parser / Syntax Analysis):**  
   محلل نحوي تعاودي منضبط (Recursive Descent Parser) يطبق القواعد النحوية المحددة بصيغة BNF، ويبني شجرة الإعراب النحوية (AST) ويكتشف الأخطاء الإملائية والتركيبية بدقة متناهية.

3. **التحليل الدلالي (Semantic Analysis & Type Checking):**  
   بناء جداول الرموز الهرمية ذات النطاقات (Nested Scopes & Symbol Tables)، والتحقق من تعريف المتغيرات قبل استخدامها، وفحص توافق الأنواع، ومنع تعديل الثوابت.

4. **توليد الكود الوسيط (Intermediate Code Generation - 3AC):**  
   تفكيك العمليات الحسابية والمنطقية المعقدة وتوليد شفرة ثلاثية العناوين (Three-Address Code) لتسهيل الفهم والمراجعة الأكاديمية والتحسين.

5. **توليد لغة التجميع (Code Generation - Assembly x64):**  
   ترجمة الشفرة الوسيطة إلى أوامر أسمبلي تحاكي المعالجات الحقيقية، مع تقسيم الذاكرة إلى قسم البيانات (`.data`) وقسم الأوامر والتعليمات (`.text`).

6. **الآلة الافتراضية وبيئة التنفيذ (Virtual Machine Runtime):**  
   آلة افتراضية مدمجة تنفذ البرنامج في الذاكرة بأمان، وتدير المكدس وعمليات الإدخال والإخراج التفاعلية، وتعرض النتائج فوراً على الشاشة.

## 🧪 أمثلة الكود العربي الجاهزة

يحتوي مجلد [`examples/`](examples/) على 17 برنامجاً عملياً متكاملاً يغطي كافة جوانب اللغة:

| رقم المثال | اسم الملف | ما يوضحه المثال |
| :---: | :--- | :--- |
| **01** | `01_طباعة_بسيطة.arb` | طباعة النصوص والأرقام والترحيب. |
| **02** | `02_متغيرات_وحساب.arb` | الإعلان عن المتغيرات وتخزين القيم والعمليات الحسابية. |
| **03** | `03_عمليات_حسابية_واسس.arb` | العمليات المعقدة، الأقواس، وقوى الأسس `^`. |
| **04** | `04_عمليات_منطقية.arb` | العمليات المنطقية (`و`، `او`، `ليس`) وجداول الصواب. |
| **05** | `05_جمل_شرطية.arb` | الشروط البسيطة والمتداخلة (`اذا ... حينئذ ... والا`). |
| **06** | `06_حلقة_طالما.arb` | حلقة التكرار الشرطية (`طالما ... كرر`). |
| **07** | `07_حلقة_اعد_حتى.arb` | حلقة التكرار مع فحص شرط التوقف في النهاية (`كرر ... حتى`). |
| **08** | `08_حلقة_كرر_عددية.arb` | حلقة التكرار بعداد وخطوة محددة (`كرر من .. الى .. خطوة`). |
| **09** | `09_اجراء_ومعاملات.arb` | استدعاء الإجراءات وتمرير المتغيرات بالقيمة وبالمرجع (`بالمرجع`). |
| **10** | `10_انواع_مركبة.arb` | السجلات (`سجل`) والمصفوفات. |
| **11** | `11_خطا_نحوي.arb` | نموذج لاختبار واكتشاف الأخطاء النحوية وتحديد موقعها. |
| **12** | `12_خطا_دلالي.arb` | نموذج لاختبار كشف تعارض الأنواع ومحاولة تغيير الثوابت. |
| **13** | `13_مصفوفات_وعمليات_احصائية.arb` | حساب المتوسط الحسابي، القيمة العظمى والصغرى في مصفوفة. |
| **14** | `14_سجلات_بيانات_الموظفين.arb` | إدارة سجلات الموظفين وحساب الرواتب والضرائب. |
| **15** | `15_ادخال_تفاعلي_وحسابات.arb` | قراءة مدخلات المستخدم من لوحة المفاتيح ومعالجتها. |
| **16** | `16_دوال_واجراءات_رياضية.arb` | حساب المضروب (Factorial) والمتتاليات الحسابية. |
| **17** | `17_مشروع_شامل_مصفوفات_وسجلات.arb` | مشروع متكامل يجمع المصفوفات والسجلات والإجراءات في تطبيق واحد. |
